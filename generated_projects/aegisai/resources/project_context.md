# AegisAI — Contexte du projet

## Vision
Plateforme de gouvernance et de coûts pour les usages d'API IA (LLM)
en entreprise : suivi des dépenses, contrôle budgétaire, conformité.

## Utilisateurs cibles
- Admin : configure les budgets, valide les dépassements, consulte la conformité
- Team Lead : suit la consommation de son équipe
- Developer : consomme les APIs IA via la plateforme

## Stack technique
Backend : Python (FastAPI), PostgreSQL
Frontend : React + TypeScript, TailwindCSS
